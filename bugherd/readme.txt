== Description ==

[BugHerd](https://bugherd.com/?utm_source=wordpress&utm_medium=plugin_directory&utm_campaign=Details_page) makes getting client feedback on websites ridiculously easy. They simply point, click and comment - BugHerd grabs a screenshot, saves technical details and creates a task for your team to track.

Install the BugHerd plugin once, send your clients or stakeholders a link, and they can start pinning feedback right away, directly onto any element of your live or WordPress staging site - no code changes, no browser extension, no client login or account setup required.

Used by web agencies, in-house dev teams, QA testers, freelancers, and marketing teams worldwide, the BugHerd visual website feedback and bug tracking tool is trusted by over 350,000 people across 10,000+ companies in 172 countries.

Every piece of feedback automatically captures a screenshot plus full technical metadata: browser, OS, screen resolution, URL, CSS selector, and more.

Feedback flows straight into BugHerd's built-in Kanban board, or syncs with your favorite developer or PM tools.

== BugHerd Key Features ==
#### Feedback pinned to the exact element on a web page
Clients and teammates click any element on your live WordPress site or WP Admin to leave a comment. Feedback is anchored to that specific element so your developer knows exactly what needs fixing - no more vague emails. [Learn more](https://bugherd.com/feature/easy-website-annotations?utm_source=wordpress&utm_medium=plugin_directory&utm_campaign=Details_page)

#### Automatic screenshot & full technical data captured
A screenshot along with browser type, OS, screen resolution, and the exact URL are all captured automatically with every piece of feedback. Your team gets everything they need to reproduce and fix an issue without a single follow-up question. [Learn more](https://bugherd.com/feature/actionable-bug-reports?utm_source=wordpress&utm_medium=plugin_directory&utm_campaign=Details_page)

#### No client account or login required
Clients don't need to create an account or install anything. Send them a link to your BugHerd project and they can start leaving feedback immediately, directly on the page, in their browser. [Learn more](https://support.bugherd.com/en/articles/11424313-get-feedback-from-clients-on-websites-and-files?utm_source=wordpress&utm_medium=plugin_directory&utm_campaign=Details_page)

#### Task Tracking
Every comment becomes a trackable task on a Kanban board, so your team can prioritize and resolve feedback easier than ever. If you’re already using a PM tool? Send tasks there with one click. [Learn more](https://bugherd.com/feature/integrated-kanban-board?utm_source=wordpress&utm_medium=plugin_directory&utm_campaign=Details_page)

#### Deep two-way integrations
BugHerd has true two-way integrations with all major project management tools, such as Jira, ClickUp, monday.com, Asana, and more; as well as supporting integrations with collaboration tools like Slack & MS Teams, and developer tools like GitHub.  BugHerd also has a fully featured API and Webhook support enabling custom integrations with any application. [Learn more](https://bugherd.com/integrations?utm_source=wordpress&utm_medium=plugin_directory&utm_campaign=Details_page)

#### Video feedback for complex issues
For feedback that's hard to describe in text, clients and teammates can record a short video walkthrough directly on a web page. The recording attaches to the task alongside a screenshot and user metadata. [Learn more](https://bugherd.com/feature/video-feedback?utm_source=wordpress&utm_medium=plugin_directory&utm_campaign=Details_page)

#### Public feedback widget for ongoing feedback on live sites
Visitors can QA your website and leave comments even after your website project has finished. The always-on public widget runs a continuous feedback loop on your live WordPress site. [Learn more](https://bugherd.com/feature/public-feedback?utm_source=wordpress&utm_medium=plugin_directory&utm_campaign=Details_page)

== How to install the BugHerd WordPress plugin ==

1. Log in to your WordPress Admin.
2. Go to Plugins → Add New.
3. Search for "BugHerd" and click Install Now, then Activate.
4. Go to Settings → BugHerd and enter your Project Key (find it in your BugHerd project under Settings).
5. Optionally enable "Show BugHerd on WP Admin pages" to collect feedback on Admin pages too.
6. Open your site — the BugHerd sidebar appears on the right, ready for feedback.

**Need help installing BugHerd?** Follow the [BugHerd WordPress Installation Guide](https://support.bugherd.com/en/articles/11425578-install-the-bugherd-wordpress-plugin) for help or email [support@bugherd.com](mailto:support@bugherd.com)


== Frequently Asked Questions ==

#### What does the BugHerd WordPress plugin do?
The BugHerd WordPress plugin lets your team and clients leave visual feedback directly on your WordPress website. They click any element on the web page, add a comment, and BugHerd automatically captures a screenshot plus user technical details like browser, OS, and device details. Every comment becomes a task on a Kanban board, or syncs two-way to your project management tool - Jira, Asana, ClickUp, Linear, Trello, and more.

#### Do I need a BugHerd account to use this plugin?
Yes. The plugin connects your WordPress site to a BugHerd project using a Project Key from your account. All plans include a free 7-day trial, no credit card required. [See current BugHerd pricing](https://bugherd.com/pricing?utm_source=wordpress&utm_medium=plugin_directory&utm_campaign=Details_page)

#### Do my clients need to install anything or create an account?
No. Clients receive a link to your BugHerd project and can leave feedback directly on the site in their browser - no account, no extension, no technical knowledge required. This is one of BugHerd's most valued features for agencies working with non-technical clients.

#### Does the BugHerd plugin work on staging and local environments?
Yes. BugHerd works on staging URLs, local development environments, and live production sites. It also works on WordPress Admin pages if you enable that option, which is useful for flagging issues with post metadata, required tags, or page configuration before going live.

#### Does BugHerd have two-way Jira integration?
Yes. BugHerd has a native two-way sync with Jira. Feedback submitted on your WordPress site creates issues in Jira automatically. When your team updates status, adds comments, or resolves issues in Jira, those changes sync back to BugHerd. The same two-way sync is available for Asana, ClickUp, Linear, Monday.com, Trello, and GitHub. [See all BugHerd integrations](https://bugherd.com/integrations?utm_source=wordpress&utm_medium=plugin_directory&utm_campaign=Details_page).

#### Will BugHerd conflict with Elementor, Bricks Builder, or other page builders?
BugHerd is compatible with most WordPress themes and page builders. If you experience a conflict on a specific page, add `?disable_bugherd` to the URL to prevent BugHerd loading there. You can also define custom query parameters in the plugin settings.

#### Can I use BugHerd on multiple WordPress sites?
Yes. All BugHerd plans include unlimited projects. Install the plugin on as many WordPress sites as you need, each connected to a different BugHerd Project Key, with no extra charge per site.

#### Can I keep collecting feedback after a site goes live?
Yes. BugHerd's [Public Feedback widget](https://bugherd.com/feature/public-feedback?utm_source=wordpress&utm_medium=plugin_directory&utm_campaign=Details_page) lets you collect ongoing feedback from real visitors on your live site without inviting them to a project. Designed as an always-on feedback channel for post-launch sites and ongoing maintenance retainers.

#### How do I find my Project Key in BugHerd?
Log in to your BugHerd account, open the relevant project, and go to Settings. Your Project Key is listed there. [Click here for full instructions](https://support.bugherd.com/en/articles/11425578-install-the-bugherd-wordpress-plugin).
